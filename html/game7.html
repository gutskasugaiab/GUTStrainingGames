このゲームについて

「ショートカットリズムゲーム」は、音楽のリズムに合わせて ショートカットキーを入力するリズムアクションゲームです。
Ctrl、Altなどの修飾キーを使い、実際のパソコン操作で使われるショートカットを楽しく覚えられます。

画面に表示される操作内容を確認し、 タイミングよく対応するキーを入力します。
正確に入力するほど高い判定を獲得でき、コンボをつなげることでスコアボーナスも上昇します。

難易度はEASY・NORMAL・HARD・EXTREMEの4種類。
難易度が上がるほど表示される情報が少なくなり、より素早い判断と正確な入力が求められます。

🕹️ 操作方法

🎮 基本の流れ

1. 難易度を選択
2. 表示された操作内容を確認
3. リズムに合わせてキーを入力
4. コンボをつないでハイスコアを目指す

⌨️ ショートカット入力

・Ctrl、Altなどの修飾キーと対応するキーを入力します
・例：「コピー」→ Ctrl + C
・例：「保存」→ Ctrl + S
・例：「元に戻す」→ Ctrl + Z

🎵 リズム判定

PERFECT!・GREAT・GOOD・MISS・BADの5段階で判定されます。

🎯 各難易度

EASY：キーを確認しながらプレイできます。
NORMAL：一部の情報が隠されます。
HARD：ショートカットを覚えて入力します。
EXTREME：60秒間のランダム出題に挑戦します。
