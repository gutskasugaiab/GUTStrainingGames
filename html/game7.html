このゲームについて

「ショートカットリズムゲーム」は、音楽のリズムに合わせて ショートカットキーを入力するリズムアクションゲームです。
Ctrl、Altなどの修飾キーとアルファベットキーを組み合わせ、 実際のパソコン操作で使用されるショートカットを楽しく覚えることができます。
ショートカットの知識、タイミング感覚、反射神経が試されるゲームです。

画面中央に表示される操作内容を確認し、 タイミングよく対応するキーを入力すると成功になります。
正確なタイミングで入力するほど高い判定を獲得でき、 コンボをつなげることでスコアボーナスが上昇します。

ゲームには EASY、 NORMAL、 HARD、 EXTREME の4種類の難易度があります。
難易度が上がるほど表示される情報が少なくなり、 より正確なショートカット入力が求められます。

EASYではショートカットキーが表示されるため、 基本的な操作を覚えながらプレイできます。
NORMALでは一部のキーが隠され、 HARDでは修飾キーと入力キーの両方を判断する必要があります。
EXTREMEでは60秒間のランダム出題に挑戦し、 瞬時の判断力と入力精度が試されます。

🕹️ 操作方法

🎮 基本の流れ

1. ゲームを開始
2. 難易度を選択
3. 表示された操作内容を確認
4. リズムに合わせてショートカットキーを入力
5. 正確な入力でスコアを獲得
6. ハイスコアを目指す

⌨️ ショートカット入力方法

・Ctrl、Altなどの修飾キーを押しながら対応するキーを入力します
・例：「コピー」→ Ctrl + C
・例：「保存」→ Ctrl + S
・例：「元に戻す」→ Ctrl + Z
・正しいキー入力に成功すると判定が表示され、スコアを獲得できます

🎵 リズム判定について

・画面のノーツがキーに到達するタイミングで入力します
・入力タイミングによって判定が変化します

PERFECT!：最高評価
GREAT：高評価
GOOD：成功判定
MISS：タイミングを逃した場合
BAD：間違ったキーを入力した場合

🏆 コンボ・スコア

・連続して成功するとコンボが発生します
・コンボ数が増えるほどスコアボーナスが上昇します
・ミスや入力間違いでコンボがリセットされます
・ゲーム終了後、スコア・最大コンボ・判定結果を確認できます

🎯 各難易度について

EASY
ショートカットキーが表示されます。
基本操作を覚えながらプレイできます。

NORMAL
一部のキーが隠されます。
操作内容から正しいキーを判断する必要があります。

HARD
ショートカットキーが表示されません。
覚えた知識と反射神経が求められます。

EXTREME
60秒間、ランダムに出題されるショートカットに挑戦します。
制限時間内でどれだけ高いスコアを獲得できるかを競います。
